#  Movie Review Sentiment Analysis using NLP

A machine learning project that analyzes movie reviews and classifies them as **Positive** or **Negative** using Natural Language Processing (NLP) and the Multinomial Naive Bayes algorithm.

##  Project Overview

Sentiment Analysis is a Natural Language Processing (NLP) technique used to identify the emotional tone of text.

In this project, a machine learning model is trained on labelled movie reviews to predict whether a review expresses positive or negative sentiment.

The project demonstrates the complete NLP workflow, including text preprocessing, feature extraction, model training, prediction, and evaluation.

##  Objectives

- Load a labelled movie review dataset.
- Clean and preprocess text data.
- Remove stop words and perform stemming.
- Convert text into numerical features using Bag of Words.
- Train a Multinomial Naive Bayes classifier.
- Evaluate the model using accuracy, precision, recall, F1-score, and a confusion matrix.
- Predict sentiment for new movie reviews.

##  Dataset

**Dataset:** NLTK Movie Reviews Corpus

The dataset contains 2,000 movie reviews categorized into:

- Positive reviews
- Negative reviews

The dataset is downloaded automatically using the NLTK library.

##  Project Workflow

1. Load the labelled movie review dataset.
2. Explore the dataset and sentiment distribution.
3. Convert text to lowercase.
4. Remove punctuation and unwanted characters.
5. Remove stop words while retaining negation words.
6. Apply stemming using Snowball Stemmer.
7. Split data into training and testing sets.
8. Extract text features using CountVectorizer.
9. Train the Multinomial Naive Bayes classifier.
10. Predict sentiment on test reviews.
11. Evaluate model performance.
12. Test the model on custom reviews.

##  Machine Learning Algorithm

### Multinomial Naive Bayes

Multinomial Naive Bayes is a probabilistic classification algorithm commonly used for text classification tasks. It works well with discrete features such as word counts generated by Bag-of-Words.

In this project, it is used to classify movie reviews into positive and negative sentiment categories.

##  Feature Extraction

**CountVectorizer** is used to convert text into numerical features.

The model uses:
- Bag-of-Words representation
- Unigrams and bigrams
- Word frequency counts

These features allow the machine learning algorithm to process textual data.

##  Model Evaluation

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The actual evaluation results are generated when the notebook is executed.
